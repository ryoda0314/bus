# 「次のバス」紹介動画（BusPromo・1920x1080・30fps・43秒）

学内連絡バスのカウントダウン（このリポジトリのアプリ）の紹介アニメーション。ナレーションなし・BGM と効果音のみ。
作り方は `作成したもの/isct/promo-video`（ScienceTokyo App の紹介動画）と同じ Remotion の構成にしている。

- 端末の中は**アプリの実物**。`../index.html` をそのまま iframe で開き、時計と state（乗り場・方面・言語・乗るバス）を動画のフレームから決めて描き直している（アプリのコードは変えない）。文言やデザインを変えても、書き出し直せば動画に反映される。
- 見た目は **iPhone のネイティブ版（`../ios/`）** に合わせている。画面の作りは index.html と同じなので、違うところ（乗るバスの画面の一文・数字の大きさ）だけを足している。ロック画面のライブアクティビティ・Dynamic Island・ホーム画面のウィジェットは、ネイティブ版のコード（`RideLiveActivity.swift`・`RideWidget.swift`）と同じ並びと文言で動画側に描いている。
- BGM と効果音は numpy で合成（外部素材なし。ライセンス表記は不要）。
- 端末は **iPhone 18 Pro Max の3Dモデル**（three.js で描く。前作の最高傑作版と同じ作り）。

## 使い方

すべて `promo-video/` で実行する。初回だけ `npm install`（Python 3 と numpy も使う）。

| コマンド | 内容 |
|---|---|
| `npm run studio` | Remotion Studio で `BusPromo` をプレビュー |
| `npm run frames -- 120 780` | 指定フレームを `out/frames/` に静止画で書き出す（`--scale=1` で原寸） |
| `npm run render` | `out/bus-promo.mp4` に書き出す（1〜2分） |
| `npm run render:3d` | 別の版（端末を傾けて、画面が切り替わるところで回す）を `out/bus-promo-3d.mp4` に書き出す |
| `npm run render:web` | Web 版だけの動画を `out/bus-promo-web.mp4` に書き出す（QR コードも作り直す） |
| `npm run qr` | Web 版のエンドカードの QR コードを作る（`public/web/qr.png`。URL は `src/theme.js` の `WEB_URL`） |
| `node render.mjs --scale=0.5` | 半分の大きさの確認用 `out/bus-promo_half.mp4`（`--id=BusPromo3D` で別の版） |
| `npm run audio` | BGM と効果音を作り直す（`public/audio/`。`--check` で波形とスペクトログラムも） |
| `npm run model -- "<.blend のパス>"` | 3Dモデルを書き出す（`public/model/iphone.glb` と `src/model.json`。Blender 4.5 を使う） |

`studio` / `frames` / `render` の前に `sync_app.mjs` が走り、アプリ本体（`../index.html` とアイコン）を `public/app/` にコピーし、
時刻表（`STOPS`）を `src/timetable.json` に書き出す。どちらも生成物なので git には入れていない。

## 構成（BGM が 120 BPM なので 1小節 = 60フレーム。区切りは [src/theme.js](src/theme.js) の `T`）

| 180–240 | 6–8 | アイコンと名前「次のバス」（ピンポーン）。8秒で幕が上がる | |
| 240–420 | 8–14 | 01 カウントダウン：端末が入り、ヒーローに寄って ①あと何分何秒 ②到着予定 ③並ぶ列 を囲む | |
| 420–600 | 14–20 | 02 乗り場・経路：工学部前 → 人科前 → 豊中、直行 → 箕面経由 → すべて を拍ごとにタップ。左の経路図も連動 | |
| 600–720 | 20–24 | 03 これに乗る：12:45 直行の「乗る」→ 乗るバスの画面 | |
| 720–780 | 24–26 | 早送り（12:35:44 → 12:43:00） | スネアのロール |
| 780–840 | 26–28 | 発車2分前でちょうど赤く点滅「発車2分前は、赤く点滅。」 | 一撃 |
| 840–945 | 28–31.5 | 04 ロック画面：サイドボタンで画面を消す → ロック画面の下にライブアクティビティ（大きくしたカードも） | ブレイク |
| 945–1020 | 31.5–34 | 上にスワイプしてロック解除 → ホーム画面の Dynamic Island（バス・12:45・残り時間）に寄る | ブレイク・フィル |
| 1020–1140 | 34–38 | かゆいところにも、手が届く：日本語 → 한국어／運休日（土曜 → 次は 10/13(火)）／ホーム画面のウィジェット | |
| 1140–1290 | 38–43 | エンドカード（非公式の一言つき）。バスが走ってきて、曲の最後の一打（1200f）で真ん中に止まる | 最後の一打・余韻 |

場面のコードは [src/scenes/](src/scenes/)。下の「路線図」（章を停留所に見立てたもの）は `Features.jsx`。

## Web 版だけの動画（BusPromoWeb・`out/bus-promo-web.mp4`）
iPhone のネイティブ版の機能（ウィジェット・ライブアクティビティ・Dynamic Island）は出さず、ブラウザで使う Web 版（`WEB_URL` = https://bus-gamma-two.vercel.app/）だけを紹介する。
尺・曲・01〜03 の流れは同じ（`Features.jsx`・`More.jsx`・`EndCard.jsx` の `variant = 'web'`）。
- 端末の中は Safari で開いた index.html のまま（ネイティブ版に合わせた一文や数字の大きさの手直しはしない）。下に Safari のバー（アドレスとツールバー）を描き、ページの表示域はその上まで。
- 01 の出だしで、アドレス欄に URL を打ち込み、白い画面からページが開く（「開いた瞬間、あと何分か、わかる。」につなげる）。
- 04 は「ホーム画面に置けば、アプリのように。」：共有ボタン →「ホーム画面に追加」→「追加」→ ホーム画面にアイコンが入る → タップして全画面で開く（Safari のバーが消える）→「電波がなくても、そのまま使える。」（機内モードのステータスバーとカード）。オフラインで動くのは、アプリの Service Worker が一度開いたファイルをキャッシュするため。
- 共有シートと「ホーム画面に追加」の画面は、iOS の並びに似せた簡単な絵（[src/scenes/WebHome.jsx](src/scenes/WebHome.jsx)。共有先は名前のない仮の丸）。
- ほかにも：3台目は「パソコンでも」（PC のブラウザの窓。幅が広いと、アプリは真ん中に 480px の列で出る）。
- エンドカードは左に名前とひと言・URL、右に QR コード（[make_qr.py](make_qr.py) が `WEB_URL` から作る）。書き出した動画のコマから QR を読み取れること（原寸と 640x360 に縮めたもの）を確かめてある。
- 公開中の Web 版を iPhone で開くと、乗るバスの画面に Scriptable 用の「ロック画面のウィジェットに表示」ボタンが出る（index.html の `IS_IOS`）。この動画では出していない。

## 別の版（BusPromo3D・`out/bus-promo-3d.mp4`）
尺・曲・見出しは同じで、端末の動きだけが違う（`Features.jsx` と `More.jsx` の `variant = '3d'`）。
- 端末を章ごとに斜めに置いて（左に 15〜24°向け、少し後ろへ倒す）、フレームの厚みを見せる。止まっているあいだは動かさない（文字が震えないように）。寄るときは正面に近づけて読みやすくする。
- 登場は裏向きから回って入り、退場は回りながら右へ抜ける。
- 「乗る」を押したあと1回転し、裏を向いているあいだ（回転の真ん中）に乗るバスの画面へ切り替わる（`RIDE_SPIN`）。
- ロック画面へは、端末が横を向いてサイドボタン（モデルの右の側面、y = 93〜190）を押すところを見せ、正面に戻るとロック画面になっている（`SIDE_TURN`）。
- ロック解除も1回転し、裏を向いているあいだにホーム画面へ（`UNLOCK_SPIN`）。そのあと Dynamic Island が広がる。
- 「ほかにも」の3台は内向きに傾け、回りながら並ぶ。
- 画面が裏や真横を向いているあいだは、DOM の画面（アプリの iframe）を見えなくしている（`ModelPhone.jsx`。外すと iframe が読み込み直しになるので visibility で隠す）。
- 背面のロゴは見せない（他社の商標を映さない）。ロゴの形の穴があるので、消さずに背面と同じすりガラスで塗っている。

## 端末の中のアプリについて（[src/AppScreen.jsx](src/AppScreen.jsx)）

- `public/app/index.html` を iframe で開く。`?ios=1` は付けない（付けると Scriptable 用の「ロック画面のウィジェットに表示」ボタンが出るが、ネイティブ版には無い）。
- 読み込んだあと、ページの外から次のことだけをする：
  - `Date.now` を動画の時刻に差し替え、1秒ごとの `setInterval(tick)` を止める。描き直しは毎フレーム `renderTabs()` と `tick()` を呼ぶ。
  - `state`（乗り場・方面・言語・乗るバス）を毎フレーム設定する。タップの印は動画側で重ねて描くだけで、実際の click は起こさない（state はタップしたフレームで切り替える）。
  - 「まもなく」の点滅（CSS アニメーション）を止めて、位相を動画の時刻で決める。赤くなった瞬間（780f）は明るい側から始まる。
  - Noto Sans JP を読み込む（アプリの font-family に入っている名前なので、そのまま効く）。
  - ネイティブ版に合わせて、乗るバスの画面に「ロック画面のウィジェットにも表示されます」（`RideScreen.swift` の lockHint）を足し、カウントダウンの数字を時刻表 60px・乗るバス 92px の Heavy にする。
- 動画の中の「いま」は **2026-10-08（木）12:35:20** から1秒ずつ進む（[src/theme.js](src/theme.js) の `appNow`）。早送りだけ 12:43:00 まで一気に進め、12:45 発の便が「あと2分」で赤くなるのが曲の一打（780f）に重なるようにしてある。
- 「ほかにも」の端末は、한국어 が 12:35:28、運休日が **2026-10-10（土）10:00**（10/11 は日曜、10/12 は祝日なので次は 10/13(火)）。
- ロック画面・Dynamic Island・ホーム画面のウィジェットはアプリの外なので動画側で描いている（[src/scenes/LockScreen.jsx](src/scenes/LockScreen.jsx)・[src/scenes/Home.jsx](src/scenes/Home.jsx)）。
  - ライブアクティビティ（ロック画面）：`RideLiveActivity.swift` の LockScreenView と同じ並び（乗るバス／豊中 → 吹田／12:45発 直行／到着予定、右に残り時間）。
  - Dynamic Island：コンパクト表示（左にバスと発車時刻、右に残り時間）。端末の島の位置から画面の中央へ広がる。
  - ホーム画面のウィジェット：`RideWidget.swift` の systemMedium と同じ並び。
  - 文言は、ネイティブ版が 12:45 直行の便で作る値（`Strings.swift` の kind・arrival など）と同じ。
- ホーム画面のほかのアプリは、名前のない仮のアイコンにしている（実在のアプリに似せない）。
- 書き出しのログに出る `A bad HTTP response code (404) was received when fetching the script.` は、アプリの Service Worker（sw.js をコピーしていない）の登録が失敗しているだけで、問題ない。
  最後に出ることがある `ProtocolError (Target.detachFromTarget)` も、書き出し後にブラウザのタブを閉じるときのログで問題ない。

## 端末（iPhone 18 Pro Max の3Dモデル・[src/ModelPhone.jsx](src/ModelPhone.jsx)）
- `Downloads/iphone-18-pro-max-high-quality-3d-model/source/Iphone_18_.blend` を、[model/export_iphone.py](model/export_iphone.py) で glb に書き出して使う（`npm run model -- "<.blend のパス>"`。Blender はバックグラウンドで、.blend に埋め込まれたスクリプトは動かさない設定で開く）。
  - 本体（Object_7）だけを書き出す（床の板は入れない）。元のデータは少し後ろに傾いているので、表示部分（マテリアル Material.001）の向きを測ってまっすぐにし、表示部分の中心を原点・正面を +Z・上を +Y・1単位 = 画面の 1px（表示部分の高さ 852）にそろえる。
  - 同じスクリプトが、表示部分の大きさ（393.7x852）・角の丸み（51.6px）・ダイナミックアイランドの位置と大きさ（幅 67px、中心から少し右）を測って `src/model.json` に書く。
- 本体（フレーム・厚み・ボタン・カメラ）は three.js（WebGL）で描き、画面の中身は DOM（実アプリの iframe）のまま、表示部分の4隅を投影した位置へ `matrix3d` で貼る（前作 `src/film/ModelPhone.jsx` と同じ）。ダイナミックアイランドはモデルと同じ位置に DOM で描く。フレームの色はアプリの紺に寄せた深い藍。
- 書き出しと静止画では、ブラウザの GL を ANGLE にしている（`render.mjs`・`preview_frames.mjs`）。
- ガラスの映り込みは、主役の端末で 0.6 倍にしている（そのままだと紺の画面が白っぽくかすむ）。
- ガラスは本体と別に描いて上に重ねるので、そのままだと本体の奥のガラス（背面のレンズのカバーなど）まで描かれ、横から見ると透けて見える。本体の写しを「奥行きだけ」先に描いて、隠れるガラスは描かないようにしている（`ModelPhone.jsx` の occluder）。
- アプリの iframe の下地は紺にして、ステータスバーに 1px 重ねている（白だと、端末を傾けたときに境目が細い線になってにじむ）。
- **`public/model/` は git に入れていない。** 3Dモデルの配布元のライセンス（クレジット表記が要るか、動画での公開や再配布ができるか）を確かめてから扱いを決める。ダウンロードしたフォルダにはライセンスのファイルが入っていない。

## 文字のちらつき・震えを出さないために
- 端末は止まっているあいだ動かさない（ゆっくり揺らすと、中の小さな文字が毎コマ 1px 未満ずつ動いて震えて見える）。
- ばね（[src/theme.js](src/theme.js) の `sp`）は、落ち着いたら（ずれ 0.3% 未満）ぴったり止める。小さな揺れ戻りで見出しが震えないように。
- 書き出しはコマを PNG で撮り（Remotion の既定の JPEG 画質80だと、文字のまわりのノイズが毎コマ変わってちらつく）、H.264 は crf 15・preset slow（[render.mjs](render.mjs)）。
- 経路図のバスは、出発地の側が変わるたびに今いる端から反対の端へ走って止まる（1周ごとに消えたり、向きが変わった瞬間に反対側へ飛んだりしない）。

## 冒頭の時刻表と経路図
- 冒頭の掲示は、3つの乗り場の時刻を1枚に並べた**架空の掲示物**（時刻と直行の印は index.html の時刻表と同じ）。実際の掲示のデザインを再現したものではない。
- 経路図の位置関係は模式的。所要時間（直行 約30分・箕面経由 約40分 など）は index.html の `express`・`via` から出している。

## 音（[make_audio.py](make_audio.py)）
- BGM は 120 BPM・D メジャー。ドロップからは王道進行（Gmaj7 – A – F#m7 – Bm7）、ロック画面の場面は3小節のブレイク（Em7 – F#m7 – Asus4・A）、最後は Em7 – A7 – D で終わる（最後の一打は 40 秒）。エレピは FM、メロディは鉄琴、ほかにベース・パッド・ドラム。
- 耳で確かめる前に数字で合わせている：ステムごとの聴感の大きさ（K 特性の近似の RMS）を目標値にそろえ、曲だけで -14.5 LUFS 前後。`python make_audio.py --check` で `out/audio_check.png`（波形と小節線つきのスペクトログラム）を描ける。
- 効果音：pop（吹き出し・カード）、tap（タップ）、swish / whoosh（場面の切り替え）、pinpon（降車ボタン風。曲の調に合わせて F#6 → D6）、ff（早送りのカチカチ。数字が変わるコマに合わせてある）、lock（サイドボタンで画面が消える）、sparkle（ライブアクティビティが出る）、swish（ロック解除）、pop（Dynamic Island が広がる）。置き場所は [src/BusPromo.jsx](src/BusPromo.jsx) の `SFX`。
- 書き出しは 16bit なので、動画の中では曲を 0.8 倍にして重なりでも割れないようにし、[master_audio.py](master_audio.py) で -14.5 LUFS 前後・ピーク -1 dBFS に整えてから AAC 320k でつなぐ。
