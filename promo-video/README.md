# 「次のバス」紹介動画（BusPromo・1920x1080・30fps・41秒）

学内連絡バスのカウントダウン（このリポジトリのアプリ）の紹介アニメーション。ナレーションなし・BGM と効果音のみ。
作り方は `作成したもの/isct/promo-video`（ScienceTokyo App の紹介動画）と同じ Remotion の構成にしている。

- 端末の中は**アプリの実物**。`../index.html` をそのまま iframe で開き、時計と state（乗り場・方面・言語・乗るバス）を動画のフレームから決めて描き直している（アプリのコードは変えない）。文言やデザインを変えても、書き出し直せば動画に反映される。
- BGM と効果音は numpy で合成（外部素材なし。ライセンス表記は不要）。
- 端末は **iPhone 18 Pro Max の3Dモデル**（three.js で描く。前作の最高傑作版と同じ作り）。

## 使い方

すべて `promo-video/` で実行する。初回だけ `npm install`（Python 3 と numpy も使う）。

| コマンド | 内容 |
|---|---|
| `npm run studio` | Remotion Studio で `BusPromo` をプレビュー |
| `npm run frames -- 120 780` | 指定フレームを `out/frames/` に静止画で書き出す（`--scale=1` で原寸） |
| `npm run render` | `out/bus-promo.mp4` に書き出す（1〜2分） |
| `node render.mjs --scale=0.5` | 半分の大きさの確認用 `out/bus-promo_half.mp4` |
| `npm run audio` | BGM と効果音を作り直す（`public/audio/`。`--check` で波形とスペクトログラムも） |
| `npm run model -- "<.blend のパス>"` | 3Dモデルを書き出す（`public/model/iphone.glb` と `src/model.json`。Blender 4.5 を使う） |

`studio` / `frames` / `render` の前に `sync_app.mjs` が走り、アプリ本体（`../index.html` とアイコン）を `public/app/` にコピーし、
時刻表（`STOPS`）を `src/timetable.json` に書き出す。どちらも生成物なので git には入れていない。

## 構成（BGM が 120 BPM なので 1小節 = 60フレーム。区切りは [src/theme.js](src/theme.js) の `T`）

| フレーム | 秒 | 内容 | 曲 |
|---|---|---|---|
| 0–120 | 0–4 | 掲示の時刻表に「いま 12:35」。吹き出し（直行は、どれ？／箕面経由って？／今日は運行日？）→「次のバス、あと何分？」 | イントロ（時計の音）・ライザー |
| 120–180 | 4–6 | 分のセルが中央に吸い込まれ、アプリと同じ形の「あと4分36秒」に。「時刻表を、カウントダウンに。」 | ドロップ |
| 180–240 | 6–8 | アイコンと名前「次のバス」（ピンポーン）。8秒で幕が上がる | |
| 240–420 | 8–14 | 01 カウントダウン：端末が入り、ヒーローに寄って ①あと何分何秒 ②到着予定 ③並ぶ列 を囲む | |
| 420–600 | 14–20 | 02 乗り場・経路：工学部前 → 人科前 → 豊中、直行 → 箕面経由 → すべて を拍ごとにタップ。左の経路図も連動 | |
| 600–720 | 20–24 | 03 これに乗る：12:45 直行の「乗る」→ 乗るバスの画面 | |
| 720–780 | 24–26 | 早送り（12:35:44 → 12:43:00） | スネアのロール |
| 780–840 | 26–28 | 発車2分前でちょうど赤く点滅「発車2分前は、赤く点滅。」 | 一撃 |
| 840–960 | 28–32 | 04 ウィジェット：「ロック画面のウィジェットに表示」→ ロック画面。ウィジェットを大きくしたカード | ブレイク |
| 960–1080 | 32–36 | かゆいところにも、手が届く：日本語 → 한국어／運休日（土曜 → 次は 10/13(火)）／ホーム画面に追加 | |
| 1080–1230 | 36–41 | エンドカード。バスが走ってきて、曲の最後の一打（1140f）で真ん中に止まる | 最後の一打・余韻 |

場面のコードは [src/scenes/](src/scenes/)。下の「路線図」（章を停留所に見立てたもの）は `Features.jsx`。

## 端末の中のアプリについて（[src/AppScreen.jsx](src/AppScreen.jsx)）

- `public/app/index.html?ios=1` を iframe で開く（`ios=1` で iPhone 向けの「ロック画面のウィジェットに表示」ボタンが出る）。
- 読み込んだあと、ページの外から次のことだけをする：
  - `Date.now` を動画の時刻に差し替え、1秒ごとの `setInterval(tick)` を止める。描き直しは毎フレーム `renderTabs()` と `tick()` を呼ぶ。
  - `state`（乗り場・方面・言語・乗るバス）を毎フレーム設定する。タップの印は動画側で重ねて描くだけで、実際の click は起こさない（state はタップしたフレームで切り替える）。
  - 「まもなく」の点滅（CSS アニメーション）を止めて、位相を動画の時刻で決める。赤くなった瞬間（780f）は明るい側から始まる。
  - Noto Sans JP を読み込む（アプリの font-family に入っている名前なので、そのまま効く）。
- 動画の中の「いま」は **2026-10-08（木）12:35:20** から1秒ずつ進む（[src/theme.js](src/theme.js) の `appNow`）。早送りだけ 12:43:00 まで一気に進め、12:45 発の便が「あと2分」で赤くなるのが曲の一打（780f）に重なるようにしてある。
- 「ほかにも」の端末は、한국어 が 12:35:28、運休日が **2026-10-10（土）10:00**（10/11 は日曜、10/12 は祝日なので次は 10/13(火)）。
- ロック画面とウィジェットはアプリの外なので動画側で描いている（[src/scenes/LockScreen.jsx](src/scenes/LockScreen.jsx)）。並びと文言は `../widget/BusRide.js` の accessoryRectangular と、アプリが 12:45 直行の便で渡す値（乗り場・発車時刻・直行・到着予定）に合わせてある。
- ホーム画面のほかのアプリは、名前のない仮のアイコンにしている。
- 書き出しのログに出る `A bad HTTP response code (404) was received when fetching the script.` は、アプリの Service Worker（sw.js をコピーしていない）の登録が失敗しているだけで、問題ない。
  最後に出ることがある `ProtocolError (Target.detachFromTarget)` も、書き出し後にブラウザのタブを閉じるときのログで問題ない。

## 端末（iPhone 18 Pro Max の3Dモデル・[src/ModelPhone.jsx](src/ModelPhone.jsx)）
- `Downloads/iphone-18-pro-max-high-quality-3d-model/source/Iphone_18_.blend` を、[model/export_iphone.py](model/export_iphone.py) で glb に書き出して使う（`npm run model -- "<.blend のパス>"`。Blender はバックグラウンドで、.blend に埋め込まれたスクリプトは動かさない設定で開く）。
  - 本体（Object_7）だけを書き出す（床の板は入れない）。元のデータは少し後ろに傾いているので、表示部分（マテリアル Material.001）の向きを測ってまっすぐにし、表示部分の中心を原点・正面を +Z・上を +Y・1単位 = 画面の 1px（表示部分の高さ 852）にそろえる。
  - 同じスクリプトが、表示部分の大きさ（393.7x852）・角の丸み（51.6px）・ダイナミックアイランドの位置と大きさ（幅 67px、中心から少し右）を測って `src/model.json` に書く。
- 本体（フレーム・厚み・ボタン・カメラ）は three.js（WebGL）で描き、画面の中身は DOM（実アプリの iframe）のまま、表示部分の4隅を投影した位置へ `matrix3d` で貼る（前作 `src/film/ModelPhone.jsx` と同じ）。ダイナミックアイランドはモデルと同じ位置に DOM で描く。フレームの色はアプリの紺に寄せた深い藍。
- 書き出しと静止画では、ブラウザの GL を ANGLE にしている（`render.mjs`・`preview_frames.mjs`）。
- ガラスの映り込みは、主役の端末で 0.6 倍にしている（そのままだと紺の画面が白っぽくかすむ）。
- **`public/model/` は git に入れていない。** 3Dモデルの配布元のライセンス（クレジット表記が要るか、動画での公開や再配布ができるか）を確かめてから扱いを決める。ダウンロードしたフォルダにはライセンスのファイルが入っていない。

## 冒頭の時刻表と経路図
- 冒頭の掲示は、3つの乗り場の時刻を1枚に並べた**架空の掲示物**（時刻と直行の印は index.html の時刻表と同じ）。実際の掲示のデザインを再現したものではない。
- 経路図の位置関係は模式的。所要時間（直行 約30分・箕面経由 約40分 など）は index.html の `express`・`via` から出している。

## 音（[make_audio.py](make_audio.py)）
- BGM は 120 BPM・D メジャー。ドロップからは王道進行（Gmaj7 – A – F#m7 – Bm7）、最後は Em7 – A7 – D で終わる。エレピは FM、メロディは鉄琴、ほかにベース・パッド・ドラム。
- 耳で確かめる前に数字で合わせている：ステムごとの聴感の大きさ（K 特性の近似の RMS）を目標値にそろえ、曲だけで -14.5 LUFS 前後。`python make_audio.py --check` で `out/audio_check.png`（波形と小節線つきのスペクトログラム）を描ける。
- 効果音：pop（吹き出し・カード）、tap（タップ）、swish / whoosh（場面の切り替え）、pinpon（降車ボタン風。曲の調に合わせて F#6 → D6）、ff（早送りのカチカチ。数字が変わるコマに合わせてある）、lock（画面が消える）、sparkle（ウィジェット）。置き場所は [src/BusPromo.jsx](src/BusPromo.jsx) の `SFX`。
- 書き出しは 16bit なので、動画の中では曲を 0.8 倍にして重なりでも割れないようにし、[master_audio.py](master_audio.py) で -14.5 LUFS 前後・ピーク -1 dBFS に整えてから AAC 320k でつなぐ。
